# 千面御姐 · 出图技能（qianmian-yujie-render）

## 这是什么

把「千面御姐·顾遥」IP 的设计知识打包成**可共享的层级技能**。给一句话，产出**可直接生成完整写真图的提示词**，并用 `scripts/generate.py` 调 Seedream 大模型**真正出图**。本技能是**完整闭环**：配方、脚本、校验、产物路径全在包内，整包复制到任何工作区即用，**不依赖包外任何内容**。

一句话原则：**面面不同、芯芯同一、媚而不俗。**

## 业务流程（先选型，后衍生——人不变）

```
选型（无基准图）:  拼提示词 → 脚本出 N 张候选 → 用户定 1 张最好的 → 锁为基准图
衍生（有基准图）:  以基准图为脸参考 → 换装 / 换风格 / 三视图 → 图生图 → 人不变校验
```

详见 `references/流程.md`。**三视图 / 换装 / 封面没有该形象基准图时不能直接跑**（脚本会拦）。

## 使用方式（两条路，都由入口判断决定）

1. **入口判断**：该形象**有无已确认基准图**？（用 `scripts/generate.py status` 查看 `定妆照/`，或按 `references/产物.md` 的命名规则）
2. **选型（无基准图）**：拼提示词（含锚点块）→ 脚本出**多张候选** → 用户确认 1 张 → `pick` 锁基准图。
3. **衍生（有基准图）**：以基准图为脸参考 → 拼衍生提示词（**不含锚点块**）→ `derive` 图生图 → 人不变校验。

> 用户说「给 A 换套女仆装」但 A 没有基准图 → 先走选型定基准，再衍生。这是流程硬约束。

**成片（第三路，已有图集/基准图时可选）**：用户要「一条短片 / 多镜头 / 配乐 / 旁白 / 字幕」→ 先**策划**：把 文案/姿势/镜头/连贯/音乐 一次设计成**企划书 JSON**（AI 编辑生成 + 手工可精修）→ `produce` 纯本地展开成**渲染契约** → `compose` 一键成片。也可直接手写**镜头脚本 JSON**（三种源：images/image 本地连帧零成本 + seedance 付费真动）。配方见 `references/配方库/10-策划层.md`（策划）+ `09-成片层.md`（导演+执行）。

**三层创作骨架**：① 策划（企划书=创意产物）→ ② 导演（渲染契约 shotlist，含 `continue_from` 末帧接龙 / `grade` 统一调色）→ ③ 执行（compose 出片）。**好作品先把原子内容整体策划好，再排镜头执行**——企划书是可读可改可评审的迭代单元。

## 组装黄金公式（永远这个顺序，每一层都是积木）

```
[形象锚点] + [服装] + [姿势] + [场景] + [质量尾缀] + [负面词]
```

- **服装（02）**：`[连体装 或 上装+下装] + [丝袜 × 高跟] + [配饰(可选)]`
- **姿势（03）**：`[基础体态] + [手势] + [眼神] + [镜头语言] + [光位]`
- **场景（04）**：`[环境主体] + [光线] + [氛围元素] + [道具] + [通用写真尾缀]`
- **质量（05）**：`[镜头焦段] + [光位] + [皮肤质感] + [后期风格块] + [负面词]`

**锚点（01）原样复制一字不改——只在阶段一·选型用**。阶段二·衍生锚点换成「基准图 + 人不变」，文本只描述服装/姿势/场景/质量。

## 工作流（把一句话 → 真正出图）

### 阶段一 · 选型（该形象无基准图）
1. **入口判断**：该形象**无**已确认基准图 → 走选型。
2. 读 `01-形象层`：锚点块**原样复制**；基准款/默认姿势/默认场景打底。
3. 读 `02-服装层`/`03-姿势层`/`04-场景层`/`05-质量层`：按用户描述搭积木（未指定 → 用基准款）。
4. 按黄金公式拼**完整提示词**（锚点开头，质量尾缀 + 负面词结尾）。
5. 出候选：`scripts/generate.py candidates --prompt "<完整提示词>" --n 4`。
6. 用户挑 1 张最好的 → `scripts/generate.py pick <候选目录> <文件> --name <形象码>` 锁基准图。
7. 过「选型门」（`references/校验.md` 阶段一：脸合格 + 性感质量门）。

### 阶段二 · 衍生（该形象已有基准图）
1. **入口判断**：该形象**有**已确认基准图 → 走衍生。
2. 读 `02-服装层`（换装）/`03-姿势层`（换姿势）/`04-场景层`＋`05-质量层`（换场景/风格）；**不读 `01-形象层` 锚点**。
3. 拼**衍生提示词**（**不含锚点块**，只动服装/姿势/场景/质量）。
4. 图生图：`scripts/generate.py derive --base <基准图> --prompt "<衍生提示词>"`（三视图加 `--kind 三视图`）。
5. 过「衍生门」：人不变校验（≥0.45 归档）+ 媚门；封面加封面三要素门。
6. 需要配文 → 按 `references/文案.md` 另输出（**文案不入图**）。

> 三视图/换装/封面没有该形象基准图时**不能直接跑**（脚本 `derive` 会校验基准图存在）。

### 阶段三 · 策划成片（企划书 → 成片）
1. **选题**：一句话 `pitch`（好立意胜过一切）。
2. 读形象库（`produce --inventory`）+ 配方库 01–05 + `文案.md` + 音乐库 → 定 `concept`（情绪/受众/风格）。
3. 写**企划书 JSON**（`copy` 文案原子先于 `shots` 镜头；镜头按 `establish → detail → hook` 功能链排；seedance 镜用 `continue_from` 接上一镜保证动起来不崩脸）。
4. `produce --brief 企划书 --dry-run` 评审 → 手工精修企划书。
5. `produce --brief 企划书 --emit 契约` → `compose --script 契约` 出片（`coherence.grade` 全镜统一调色）。
6. 过「成片门」（seedance 镜抽帧人不变）；看片 → 满意精选进 作品集/，不足回改企划书重跑。

## 红线（违反 = 废图）

1. **锚点块一字不改**——只在选型用；A 的脸不能配 C 的妆（形象串味 = 废图）。
2. **换装不改脸 / 衍生人不变**——衍生永远基于基准图的脸，锚点不重新生成。
3. **无基准图不能直接衍生 / 出视频**——三视图/换装/封面/`video`/`montage` 先走选型定基准。
4. **负面词必带**——露而不艳、媚而不俗；低俗/风尘/过度暴露/油腻硬禁。
5. **边界守恒**——诱惑档 ≠ 暴露档；皮肤面积可多，画面依然留白、克制、真实摄影感。
6. **查不到就停**——形象/服装/档位无法映射时，明确说出缺什么，请用户补全，不自己编。
7. **文案不入图**——配图文案单独输出，绝不拼进图提示词。
8. **视频动小不动大**——图生视频只写轻微动作（眼神/发丝/指尖），大幅动作崩脸崩形 = 废片。
9. **字幕/旁白文案合规**——成片字卡与旁白先过「媚而不俗」底线，低俗/引导词/违禁词不入片。
10. **成片门是硬门**——compose 任一 seedance 镜抽帧人不变不过 = 整条成片不能交付。
11. **连贯三件套**——成片先策划期设计（姿势/场景延续）+ `continue_from` 末帧接龙 + `grade` 统一调色；缺一个连贯就打折，别裸排镜头。

## 运行脚本（完整闭环，独立可共享）

- 环境：`cd .claude/skills/qianmian-yujie-render && uv venv && uv pip install -r scripts/requirements.txt`。
- `scripts/.env` 填 `ARK_API_KEY`（火山方舟）。用的是别的模型 → 在 .env 设 `ARK_MODEL`；视频模型 → `ARK_VIDEO_MODEL`。
- 子命令：`candidates`（出候选）/ `pick`（锁基准到定妆照）/ `derive`（衍生图生图，`--kind 三视图|栏目图`）/ `montage`（图集→9:16 动态视频，零成本，`--cuts/--cam/--text` 多镜头）/ `video`（Seedance 图生视频，可选增强，需开通，`--duration 0` + `Shot N:` 多镜头）/ `compose`（渲染契约/镜头脚本→成片：多镜头 + 音频 + 字幕 + 成片门 + 统一调色）/ `produce`（企划书→创意预览/逐镜prompt/渲染契约，`--inventory` 盘点资产）/ `status`（看已出图/视频清单）。
- 校验：人脸相似度 ≥0.45 归档 ✅ / 0.35–0.45 存疑 🟡 / <0.35 串味进拒图 ❌。图片与视频抽帧同一阈值。模型布局 `{root}/models/buffalo_l/`：脚本**自动探测** `<工作区>/models/buffalo_l/`，没有才触发 insightface 自动下载到 `~/.insightface`；也可设 `INSIGHTFACE_ROOT` 覆盖。
- **产物落 `<工作区>/qianmian-yujie-render/`**（候选/定妆照/三视图/栏目图/作品集/拒图）——脚本按技能位置自动推导工作区，分享给谁、产物就落在谁的工作区。规划见 `references/产物.md`。
- **分享**：整包复制到对方工作区 `.claude/skills/`，对方装依赖 + 填 `.env` 即用。

## Learnings

- **INSIGHTFACE_ROOT 布局是 `{root}/models/{name}/`**（实测：指到 `auto/` 而非 `auto/models/`，insightface 才认 `auto/models/buffalo_l/`，否则会去 GitHub 下载 281MB 模型）。
- **校验器真实拦截串味**（实测 2026-08-15）：同一基准图出 2 张女仆装衍生，1 张相似度存疑 0.35–0.45 归档、1 张 <0.35 判串味自动移入 `拒图/`——人不变校验不是摆设。
- **CPU 加载 buffalo_l 仅约 1.6s**（onnxruntime CPU provider），校验不会拖慢出图流程；insightface 会打 `FutureWarning`（numpy rcond / skimage estimate），属正常噪音。
- **Windows 下技能跑脚本一律用自带 `.venv/`**（`uv venv` + `uv pip install -r scripts/requirements.txt`），不要动全局/其他项目环境（会踩 numpy 版本冲突）。
