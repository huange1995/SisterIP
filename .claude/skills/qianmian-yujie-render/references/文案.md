# 文案 · 配图文案（不入图，另输出）

> **本层管「发图文案」。文案不进图提示词——图是图，文是文。**
> **阶段一·选型（出候选 / 锁基准）不配文**；**阶段二·衍生定稿**后，才按本层另输出配图文案。

## 语气规则（每条都带"顾遥味"）

- 短句、句号、慢，话留一半
- 口癖常驻：「急什么，天又塌不下来。」「想看哪一面？——得看你的诚意。」
- 不喊麦、不用感叹号轰炸、不用网梗

## 挑逗文案库（性感靠"留白"说，不靠直给）

- **开场钩子**：「早上好——要听故事，还是想看看我？」
- **留悬念**：「想留住哪一面？——可惜不能全给你。」
- **反客为主**：「高跟鞋落地的声音，你听得出是哪一面吗？」
- **留白收尾**：「水面上的我，和你想的不太一样。」/「坐好，别急着走。」

## 栏目 × 文案基调（阶段二·衍生定稿后配文）

| 栏目 | 文案基调 | 示例开头 |
|------|---------|---------|
| 千面换装 | 一面X一面Y + 互动钩子 | 「一面旗袍，一面皮衣。你想见我哪一面？」 |
| 衣装手记 | 一个物件的故事，留悬念 | 「这件，是给一位等了三年的客人做的。」 |
| 深夜爵士 | 爵士氛围 + 金句/口癖 | 「今天店里放的是爵士。急什么，天又塌不下来。」 |
| 想看哪一面 | 投票互动，要诚意 | 「得看你的诚意。」 |
| 工作室日常 | 日常私语，温柔知性 | 老洋房、红酒、暖光 |
| 腿部特辑 | 腿线留白 | 「有些性感，露在膝上三寸就够。剩下七分，你自己想。」 |

## 标签规范

`#顾遥` `#御姐` `#旗袍` `#制服` `#千面` `#温柔御姐`（＋ 专项话题如 `#丝袜高跟` `#腿部特辑`）

## 输出约定

- 配图文案：**另行输出**在图提示词之后，**不拼进图提示词**。
- 一段短文案（2–4 行）+ 标签行；封面文案要压得住三要素（红唇 / 丝袜高跟 / 眼神）。
- 诱惑梯度在文案里靠留白表达，不靠直给——与图同守「露而不艳、媚而不俗」。
