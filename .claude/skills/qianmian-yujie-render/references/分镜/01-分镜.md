# 分镜 · 分镜表（③ 分镜段 · produce --emit / 手写 / compose 执行）

> **一条分镜表 = 一条成片的设计图。** 分镜段把 ① 策划段的策划案（`../策划/01-策划.md`）
> 展开成**逐镜可执行的分镜表 shotlist JSON**：每镜定 源 / 画面内容 / 机位 / 时长，
> 再加**跨镜连贯**（`continue_from` 接龙 + 顶层 `grade` 统一调色）与**确定性时间轴**。
> 分镜表由 `compose`（`../成片/01-成片.md`）逐镜执行、拼帧成片。
>
> **分镜表 = 策划案展开产物**：策划段 `produce --emit` 自动展开；也可直接手写（向后兼容）。
> 分镜表只**设计**，不产出素材——产出在 ⑤ 素材段与 ⑥ 成片段。

| 维度 | 分镜能力 | 成本 |
|------|---------|------|
| 多镜头·路线 C | `images` / `image` 源本地 montage 连帧（每镜时长/硬切·溶解/机位/烧字卡） | ¥0 |
| 多镜头·路线 A | `seedance` 源图生视频，prompt 写 `Shot N:` 一次出 2–3 镜 | 按秒计费（约 ¥1/秒 720p） |
| 连贯·接龙 | `continue_from`：seedance 镜抽上一镜末帧作首帧参考（跨镜脸/姿态延续） | ¥0 |
| 连贯·调色 | `grade`：全镜拼帧前套同一套 eq+colorbalance，消除跨镜色调漂移 | ¥0 |

---

## 一、分镜表 schema（shotlist JSON）

```json
{
  "title": "深夜爵士",
  "ratio": "9:16",
  "fps": 24,
  "scenes": [
    {"id": "s1", "src": "images", "dir": "栏目图/换装秀", "per": 2.5,
     "cuts": "dissolve", "cam": "alternate", "text": "夜晚归她管"},
    {"id": "s2", "src": "image", "base": "定妆照/A-黛眉/A-黛眉.png",
     "dur": 5, "cam": "zoom-in", "text": "酒杯映着灯"},
    {"id": "s3", "src": "seedance", "base": "定妆照/A-黛眉/A-黛眉.png",
     "prompt": "Shot 1: 侧身回眸 发丝微扬 / Shot 2: 指尖划过杯沿 眼神上挑",
     "dur": -1, "firstframe": "derive", "ff_prompt": "9:16 竖版写真，御姐气质，暗调爵士酒吧",
     "continue_from": "s2", "text": "三点后的爵士"}
  ],
  "audio": {
    "bgm": "深夜爵士.mp3",
    "bgm_volume": 0.4,
    "voiceover": [{"scene": "s3", "text": "夜晚归她管，酒杯映着眼里的灯。"}]
  },
  "grade": {"brightness": 0, "contrast": 1.05, "saturation": 0.9, "warmth": 1.0}
}
```

**三种镜头源：**

| src | 产出 | 必填 | 可选 | 成本 |
|-----|------|------|------|------|
| `images` | 图集连帧（每镜 = per × 张数） | `dir`（相对 output_root） | `per` / `cuts`(dissolve·hard) / `cam` / `text` | ¥0 |
| `image` | 单图单镜 Ken Burns | `base` | `dur` / `cam` / `text` | ¥0 |
| `seedance` | Seedance 图生视频 | `base` / `prompt` | `dur`（`-1` = auto 多镜）/ `firstframe`(derive·crop) / `ff_prompt` / `continue_from`（末帧接龙） / `text` | 付费 |

**顶层 `grade`（统一调色）**：`{"brightness": 0, "contrast": 1.05, "saturation": 0.9, "warmth": 1.0}`——
每镜 clip 拼帧前套同一套（ffmpeg `eq` + `colorbalance`），消除跨镜色调漂移。
`warmth` 1.0=不变，>1 偏暖、<1 偏冷；全默认时零成本跳过。来自策划案 `coherence.grade`。

**时间轴是确定的**：同分镜表 + 同图集 = 同一 start/dur（SRT 与旁白对齐都靠它）。
`dur: -1`（auto 多镜）时时间轴按 `ARK_VIDEO_DURATION` 估算，实片可能略长。

## 二、功能链怎么排（分镜门的设计规范）

一条短片按 **establish（定调）→ detail（打脸）→ hook（收尾钩子）** 排功能链：

1. **establish 定调**：首镜必用 `images` 图集连帧（便宜、快），铺氛围、定调性。
2. **detail 细节**：`image` 单图特写（回眸/发丝），把脸打实、把情绪给足。
3. **hook 收尾钩子**：`seedance` 真动（眼神上挑/发丝微扬），`continue_from` 接上一镜保证动起来脸不崩。

> 镜头数量配情绪节奏：三镜起；情绪越是「慵懒/克制」越少镜、每镜越慢；
> 越是「紧张/高潮」越多镜、每镜越短。

## 三、连贯三件套（分镜门的关键）

1. **策划期设计**：策划案里姿势/场景尽量延续（`../策划/01-策划.md`），素材期就不打架。
2. **`continue_from` 末帧接龙**：seedance 镜抽上一镜末帧作首帧参考——跨镜脸/姿态延续。
3. **`grade` 统一调色**：顶层 `grade` 套全片所有镜，消除跨镜色调漂移。

> 缺一个，连贯就打折；成片门只查脸，连贯靠分镜门把关（`../校验.md`）。

## 四、红线（分镜版）

1. **分镜表自洽**：每镜 `src` 必填对应字段（`images`→`dir`；`image`/`seedance`→`base`）。
2. **首镜定调**：`establish` 在前，别让短片开头就进 seedance 高潮镜。
3. **动小不动大**：seedance 镜动作幅度克制（`../素材/02-单镜视频.md` 动作配方）。
4. **连贯可查**：seedance 镜要么有 `continue_from`，要么有明确接续设计。
