# 校验 · 一致性检查（按阶段拆门）

> **出图后逐张核对。** 每张图要过两关：**脸**（一致性）+ **媚**（性感质量门）——都过才过关。
> 按业务阶段拆门：**阶段一·选型门** → **阶段二·衍生门** → **通用门**。

## 阶段一 · 选型门（锁基准图前必过）

基准图是后续所有衍生的「脸参考」，必须过：

- **脸合格**：正脸 / 清晰 / 无遮挡 / 无过曝，五官完整；对形象锚点语义一致（见下方一致性清单）。
- **性感质量门**：见下方通用门（基准图也必须是「能出图」的质量）。
- 程序侧：候选图是 `scripts/generate.py candidates` 的产物，锁定用 `pick`（见 `../流程.md` 选型六步）。

## 阶段二 · 衍生门（图生图必过）

- **人不变**：对**该形象基准图**做人脸相似度校验 —— **≥ 0.45** 归档 ✅ ／ **0.35–0.45** 存疑待人工 🟡 ／ **< 0.35** 判串味进 rejected ❌（`scripts/generate.py derive` 自动执行；无脸也判拒——人不变无法确认）。
- **人不变 = 衍生阶段的脸 = 基准图的脸**；换装 / 换风格 / 三视图只动服装 / 姿势 / 场景 / 质量，不动脸（锚点不重新生成）。
- **媚门**：见下方通用门。
- **封面门**（封面时）：见下方封面三要素门。

## 阶段二·视频门（图生视频 / 图集合成必过）

- **人不变（视频版）**：`video` 出片后自动**抽 50% / 90% 处帧** vs 基准图（insightface），阈值与图片一致 —— **≥0.45** 归档 ✅ ／ **0.35–0.45** 存疑 🟡 ／ **<0.35** 串味整批移入 `拒图/视频/` ❌。
- **首帧 = 基准图**（或其 9:16 衍生版）——起点天然一致；首帧人脸变了 = 直接废片。
- **动小不动大**：幅度克制；大幅度转身 / 快动作 / 肢体扭曲 = 崩脸崩形 = 废片。
- **montage（图集合成）**：源图每张都过图片衍生门（人不变），合成后抽查 1 帧复核即可。
- 视频配方见 `配方库/08-视频层.md`。

### 姿势积木校验（每张必过）

- **挑逗三拍至少命中一拍**？眼神递 / 指尖收 / 停在临界
- **体态 × 手势 × 眼神 是否同档**（含蓄/挑逗/诱惑）？跨档 = 违和
- **镜头语言与光位是否齐**？（全身照 + 侧/逆光勾曲线）

### 档位质量门

| 档位 | 必过 |
|------|------|
| 含蓄 | 静态体态、克制手势、含蓄眼神——「气质的媚」；露而不艳 |
| 挑逗 | 至少一拍挑逗（眼神上挑 / 指尖轻触 / 动态体态）；有留白 |
| 诱惑 | 分量足但仍在临界——留白、克制、真实摄影感；绝不滑向暴露 |

### 制服附加核对（新扩制服必查）

| 制服 | 必查 |
|------|------|
| 女警 / 特警 | 制服在？领带 / 腰带在？高跟在？ |
| 女仆 | 白围裙 + 蕾丝头饰在？ |
| 护士 | 白制服裙 + 听诊器在？ |
| 空乘 | 蓝色领巾在？ |
| 军装 | 肩章 / 腰带在？ |
| 歌女 / 舞女 | 亮片 / 流苏在？ |

### 封面三要素门（封面必过）

- **红唇**在画面？
- **丝袜高跟**在画面有存在感？
- **眼神**有挑逗感？
- **三缺一不上封面。**

### 通用性感质量门（每张必过）

- 脸型成熟不幼？**细高跟是否在画面**？丝袜是否在？是否全身照？
- 是否真实写真人像（非 CG / 塑料皮）？
- 是否**媚而不俗**——挑逗三拍至少命中一拍（眼神递 / 指尖收 / 停在临界）？有留白、不靠暴露堆性感？

**性感质量门三要素：**
1. 挑逗感有但克制，画面留白
2. 低俗/风尘/油腻/过度暴露一律重做（负面词已硬禁）
3. 腿线 + 高跟是辨识符，能露则不遮

**形象串味 = 废图**（A 的脸配了 C 的妆直接重做）。

## 程序化阈值（`scripts/generate.py` 执行）

- 选型：候选图对形象锚点语义一致 + 过性感质量门（人工确认后锁基准）。
- 衍生：insightface 对基准图做相似度校验（阈值如上）。
- **人脸相似度管「脸」，性感质量门管「媚」——两张都要过。**
