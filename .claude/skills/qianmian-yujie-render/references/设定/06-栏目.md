# 设定·栏目 · 栏目选题库（一键出入口）

> **本层是设定库之上的「预置装配」。** 用户直接说栏目名 → 查本表，配方已内置 形象×梯度×场景×姿势，一条龙拼好。
> **入口判断**：用户说栏目名 → 先看该形象**有无已确认基准图**——
> 无 → 先走阶段一·选型（`../流程.md` 选型六步）出候选锁基准；有 → 直接走阶段二·衍生按栏目换装/换场景。
> 用法：按「主形象 + 默认梯度」装配；用户改了形象/档位/场景 → 以用户为准，其余照配方。配图文案另走 `../发帖文案.md`。

## 栏目配方速查

| 栏目 | 主形象 | 默认梯度 | 场景方向 | 姿势/镜头要点 | 配文基调 |
|------|--------|---------|---------|--------------|---------|
| **千面换装** | 全形象（需指定哪一面） | 挑逗档 | 每期换，从场景层（04）选 | 全身照（封面）；可带换装过程 2–3 张连拍 | 一面X，一面Y；想看哪一面 |
| **衣装手记** | A / C | 含蓄→挑逗 | 配故事氛围（老洋房/画廊/酒吧） | 指尖轻触盘扣/衣料，回眸，中近景 | 一件衣服一个小故事 |
| **深夜爵士** | C | 诱惑档 | 酒吧 / 天台 / 海港 / 沙漠星空 | 把玩酒杯、指尖抚杯沿、回眸 | 爵士 + 金句/口癖 |
| **想看哪一面** | 全形象 | 挑逗档（互动） | 任选 | 给 2–3 面候选（同形象不同穿搭） | 投票互动，要诚意 |
| **工作室日常** | A / 日常 | 含蓄档 | 老洋房 / 衣帽间 / 红酒 | 温柔知性，暖光居家 | 日常私语 |
| **幕后三视图** | 全形象 | 无（方法论） | 设计 / AI 工作流 | 三视图（正/侧/背 + 脸特写），中性姿态 | 方法论向，不媚 |

> **全形象** = 配方不自带形象，需要用户指定「哪一面」（如：千面换装·职场 = 形象 B）。深夜爵士/衣装手记/工作室日常已内置主形象。

## 丝袜 × 高跟 · 腿部特辑配方（04 专项）

> 腿线是主角，上身从简。用于 千面换装·腿部特辑 / 深夜爵士·增刊 / 衣装手记·鞋子篇。

```
[形象锚点（原样）] ＋ [高开衩裙摆/短款下装] ＋ [丝袜：黑丝吊带/渔网/渐变/豹纹/过膝等] ＋ [高跟：尖头/红底/罗马/恨天高等]
＋ [腿线特写镜头，低机位/特写] ＋ [场景：酒吧/霓虹/居家] ＋ [主版质量] ＋ [负面词]
```

要点：
- 腿部特写时**上身从简不抢戏**（服装层 02 搭配规则 2）
- 诱惑梯度按栏目走（腿部特辑默认诱惑档）
- 灯光在腿侧拉光影（吧台/霓虹光，场景层 04 光线库）

## 一键出的完整流程（agent 执行）

1. 用户说「出一期 深夜爵士」→ 查本表：形象 C ＋ 诱惑档 ＋ 酒吧场景。
2. 取形象 C 锚点块（角色 01）**原样复制**；穿搭按栏目氛围选（晚礼服/黑蕾丝吊带裙等，穿搭 02 C 域）；姿势按诱惑档默认组合（表演 03）；场景酒吧（场景 04）；影像主版（影像 05）。
3. 输出完整图提示词（黄金公式）。
4. 配图文案 → `../发帖文案.md`「深夜爵士」基调 + 挑逗文案库，**另起一段输出，不入图**。
5. 栏目要「出成片」（一条短片）→ 走 `../策划/01-策划.md` 策划案 → `produce --emit` → `compose`（深夜爵士 有金标准策划案示例 `scripts/examples/策划案-深夜爵士-顾遥.demo.json`）。
