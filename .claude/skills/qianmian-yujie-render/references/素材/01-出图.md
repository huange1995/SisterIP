# 素材·出图 · 候选 → 基准图 → 衍生出图（⑤ 素材段 · 图是主产品）

> **图是主产品。** ⑤ 素材段把④设定库（`../设定/*`）的原子拼成提示词，出三类图素材：
> **候选 → 锁基准 → 衍生**。衍生是素材段的**主战**（换装/换风格/三视图/封面/栏目图集），
> 全部以**基准图**为脸参考；**人不变是硬前提**（`../校验.md` 素材门）。
> 单镜视频（montage/video）是素材段的另一支，见 `02-单镜视频.md`。

| 步骤 | 命令 | 产物 | 门禁 |
|------|------|------|------|
| ① 出候选 | `candidates --prompt "…" --n N` | `候选/<形象>/` | 人工挑 1 张最好的 |
| ② 锁基准 | `pick <候选图> --name <形象码>` | `定妆照/<形象>/` | 选型门（脸合格 + 性感质量门） |
| ③ 衍生 | `derive --base <基准图> --prompt "…"` | `栏目图/<tag>/`、`三视图/<形象>/` | 衍生门（人不变 ≥0.45） |

> **无基准图不能衍生**：换装/换风格/三视图/封面/单镜视频/成片在**没有该形象基准图时不能直接跑**
> （脚本与校验都会拦）——先走①② 定基准，再衍生。

## 一、出候选 + 锁基准（形象的第一张脸）

```
python scripts/generate.py candidates --prompt "<完整提示词>" --n 4
python scripts/generate.py pick 候选/A-黛眉/xxx.png --name A-黛眉
```

- 提示词按**黄金公式**：`[形象锚点 原样] + [基准款穿搭] + [基准姿势] + [基准场景] + [主版质量尾缀] + [负面词]`（五层配方见 `../设定/01-角色` `02-穿搭` `03-表演` `04-场景` `05-影像`）。
- `pick` 把用户挑中的候选**锁为基准图** → `定妆照/<形象>/`，从此该形象的「这张脸」锁定。
- 基准图要求：全身正面站姿、基准姿态、光均匀、脸清晰——它是后面所有衍生的脸参考。

## 二、衍生出图（素材段主战）

```
python scripts/generate.py derive --base 定妆照/A-黛眉/A-黛眉.png \
  --prompt "<衍生提示词>" [--tag <栏目>] [--kind 三视图] [--n N]
```

- **不含形象锚点**：脸由基准图接管，提示词只动 服装/姿势/场景/质量（`../设定/02-穿搭` `03-表演` `04-场景` `05-影像`）。
- 出图后 `derive` 自动过**衍生门**：insightface 对基准图做人脸相似度——**≥0.45 归档 ✅** ／ **0.35–0.45 存疑 🟡** ／ **<0.35 串味进 rejected ❌**（无脸也判拒——人不变无法确认）。

### 衍生方向（都基于基准图）

| 方向 | 动什么 | 命令 | 产物 |
|------|--------|------|------|
| 换装 | 服装/丝袜/高跟（02） | `derive --base … --prompt "<换装>"` | `栏目图/<tag>/` |
| 换风格 | 后期风格/光位（05/04） | `derive --base … --prompt "<风格>"` | `栏目图/<tag>/` |
| 三视图 | 正/侧/背 + 脸特写，中性姿态 | `derive --base … --kind 三视图` | `三视图/<形象>/` |
| 封面/栏目 | 内容图，封面三要素门（红唇/丝袜高跟/眼神） | `derive --base … --tag <栏目>` | `栏目图/<tag>/` |
| 栏目图集 | 同一基准图换装成 N 张 | `derive --base … --tag <栏目> --n N` | `栏目图/<tag>/` → 喂 montage 连帧 / compose 图集镜 |

## 三、素材门（出图守门，详见 `../校验.md`）

- **选型门**（锁基准前）：脸合格（正脸/清晰/无遮挡/五官方）+ 性感质量门——基准图也必须是「能出图」的质量。
- **衍生门**（图生图必过）：人不变（≥0.45，insightface）；锚点不重新生成，只动服装/姿势/场景/质量。
- **封面门**（封面时）：红唇在画面？丝袜高跟在画面有存在感？眼神有挑逗感？**三缺一不上封面**。
- **媚门**（每张必过）：媚而不俗——挑逗三拍至少命中一拍（眼神递/指尖收/停在临界）；低俗/风尘/过度暴露一律重做（负面词已硬禁）。

## 四、红线（出图版）

1. **无基准图不能衍生** —— 先 `candidates` + `pick` 定基准。
2. **锚点块不重新生成** —— 衍生只动服装/姿势/场景/质量，动脸 = 串味 = 废图。
3. **人不变是硬门** —— <0.35 进 rejected，人工复核或重出。
4. **媚而不俗** —— 负面词硬禁低俗/风尘/过度暴露；形象串味（A 的脸配 C 的妆）直接重做。
