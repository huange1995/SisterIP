# 策划 · 策划案 → 创意产物（① 策划段 · produce）

> **好作品不是「临时手拼」出来的，是「先整体策划原子内容」出来的。** 六段式流水线
> （策划→脚本→分镜→设定→素材→成片）里，**① 策划段**先把 **概念 / 脚本文案 / 分镜 /
> 穿搭设定 / 连贯 / 音乐** 一次性设计好，落成一份**策划案 JSON**（可读、可改、可评审的
> 迭代单元），再由 `produce` 纯本地零 API 展开成③分镜段能执行的**分镜表**。
>
> | 段 | 产物 | 命令 | 谁干 |
> |----|------|------|------|
> | ① 策划（本段） | **策划案** = 创意产物（concept/cast/copy/shots/music/coherence） | `produce` | AI 编辑生成 + 手工精修 |
> | ② 脚本 | **脚本文案** = 策划案内嵌 `copy[]`（字幕/旁白，绑镜） | 手写进策划案 | AI 编辑生成 + 手工精修（规范见 `../脚本/01-脚本.md`） |
> | ③ 分镜 | **分镜表** = 策划案展开（shotlist，含 grade/continue_from） | `produce --emit` | 自动，可改（schema 见 `../分镜/01-分镜.md`） |
> | ④ 设定 | **角色/穿搭/表演/场景/影像** 设定库（只读参考） | Read `../设定/*` | 编辑器选原子填进策划案 |
> | ⑤ 素材 | 候选/定妆照/栏目图/三视图/单镜视频 | `candidates/pick/derive/montage/video` | 自动 |
> | ⑥ 成片 | **成片** = 逐镜渲染→拼帧→调色→混音→字幕→封装 | `compose` | 自动（见 `../成片/01-成片.md`） |

**关键原则：策划案自包含。** 姿势/场景/质量等原子文本已经由编辑器从设定库
（`../设定/01-角色` 角色、`02-穿搭`、`03-表演`、`04-场景`、`05-影像`）、发帖文案、
音乐库**挑好填进策划案**，`produce` 不解析设定库 markdown，只做拼装与校验。

---

### 字段表

| 段 | 字段 | 必填 | 说明 |
|----|------|------|------|
| 顶层 | `title` | ✅ | 策划案名（也用作成片名） |
| | `ratio` / `fps` | | 默认 `9:16` / `24` |
| `concept` | `pitch` | ✅ | **一句话立意**（好作品从一句话开始） |
| | `mood` | ✅ | 情绪关键词数组（慵懒/克制/性感…） |
| | `audience` | | 受众，定腔调 |
| | `style_ref` | | 风格基调（暗调爵士酒吧，胶片颗粒…） |
| | `negative` | | 负面词，缺省用通用负面 |
| `cast` | `anchor` | ✅ | 角色名（定妆照目录名，见 `../设定/01-角色.md`） |
| | `anchor_prompt` | ✅ | **形象锚点**（从 `../设定/01-角色.md` 挑，自包含） |
| | `outfits[]` | ✅ | 本片用到的穿搭；`name` 供 shot 引用，`dir`=图集目录，`prompt`=穿搭描述（见 `../设定/02-穿搭.md`） |
| | `light` | | 光线（暖黄侧光…，见 `../设定/04-场景.md`） |
| `copy[]` | `id` / `text` | ✅ | **脚本文案原子**；`mode`=`subtitle`\|`voiceover`，`tone`=冷/媚/飒…，`scene`=绑到某镜。写法见 `../脚本/01-脚本.md` |
| `shots[]` | `id` / `role` | ✅ | `role`=`establish`\|`detail`\|`hook`（定调/细节/收尾钩子）。分镜设计见 `../分镜/01-分镜.md` |
| | `src` | ✅ | `images`（图集连帧）/ `image`（单图）/ `seedance`（图生视频） |
| | 各源字段 | ✅ | `images` 要 `outfit`(或 `dir`)；`image`/`seedance` 要 `base`；`seedance` 要 `pose`/`motion` |
| | `pose` / `scene` / `quality` | | 姿势/场景/质量原子（从设定库挑，自包含） |
| | `cam` / `per`(images) / `dur` | | 机位 / 每图秒数 / 镜头时长 |
| | `copy` | | 绑一条脚本文案到该镜 |
| | `continue_from` | | **接龙**：该镜首帧接上一镜末帧（跨镜连贯） |
| `music` | `bgm` / `volume` / `mood` | | 曲库文件名 / 音量 / 气质 |
| `coherence` | `face` | | 人不变规则（成片门阈值说明） |
| | `grade` | | 成片期统一调色（全片所有镜套同一套，消除跨镜色调漂移） |

## 二、produce 命令（策划段入口，纯本地零 API）

```
python scripts/generate.py produce --inventory
python scripts/generate.py produce --brief <策划案.json> --dry-run    # 创意预览（文案/镜头/音乐/连贯）→ 评审
python scripts/generate.py produce --brief <策划案.json> --prompts    # 逐镜完整 prompt（黄金公式）→ 审查提示词
python scripts/generate.py produce --brief <策划案.json> --emit <分镜表.json>  # 展开成分镜表 → 交给 compose
```

- `--inventory`：列出形象库可用资产（栏目图/穿搭集、定妆照/角色、音乐库/曲目），编辑找料用。
- 展开链：**策划案 → `--emit` 分镜表 → `compose --script 分镜表` 出片**。
- 分镜表含 `grade` / `continue_from` / `voiceover`，现有手写分镜表仍可直接 compose（向后兼容）。

## 三、编辑 Checklist（AI 编辑出策划案的工作流）

1. **选题**：一句话 `pitch`（好立意胜过一切；从 `../发帖文案.md` 挑/改造）。
2. **读形象库**：`produce --inventory` 看可用 穿搭集/定妆照/曲目。
3. **定 concept**：mood / audience / style_ref（情绪先定，镜头后定）。
4. **写 copy（② 脚本）**：按 `../脚本/01-脚本.md` 写文案原子并绑到对应镜（`scene`），subtitle 是「画面里的话」，voiceover 是「画外音」。
5. **排 shots（③ 分镜）**：按 **establish → detail → hook** 排功能链（设计规范见 `../分镜/01-分镜.md`）：
   - `establish` 定调：图集连帧铺氛围（便宜、快），首镜必是它；
   - `detail` 细节：单图特写（回眸/发丝），把脸打实；
   - `hook` 收尾钩子：seedance 真动（眼神上挑），`continue_from` 接上一镜保证动起来脸不崩。
6. **选 music**：从音乐库按 mood 选，音量 0.2–0.4 起（别盖旁白）。
7. **定 coherence**：face 规则 + grade 统一调色（跨镜色调一致靠它）。

## 四、黄金公式（策划案 → 自动拼装）

衍生（成片）路径不用形象锚点（基准图提供人脸），公式：

```
[穿搭 prompt] + [姿势 pose] + [场景 scene] + [质量 quality] + [风格基调 style_ref] + [光线 light] + 「；9:16 竖版写真；」+ [负面词]
```

- `sh.use_anchor: true` 时才前置形象锚点（首帧要从 0 出脸时）。
- seedance 镜的动作 prompt 独立拼：`Shot 1: {pose}，{motion}`（可手写 `action` 覆盖多镜）。
- 原子文本在策划案里**不重复**（quality 不重复 style_ref 的词，light 不重复 style_ref 的词），避免拼装出赘词。

## 五、金标准（好策划案 = 好作品的骨架）

1. **pitch 一句话讲得清**：说不清「这条片子讲什么」就不要排镜头。
2. **功能链完整**：establish 定调 → detail 打脸 → hook 收尾，三镜起，镜头数量配情绪节奏。
3. **脚本文案先于分镜**：copy 写在 shots 之前，分镜只是文案的画面支撑（见 `../脚本/01-脚本.md`）。
4. **连贯三件套**：策划期设计（姿势/场景尽量延续）+ `continue_from` 接龙 + `grade` 统一调色。
5. **可评审**：`--dry-run` 一眼看出 立意/情绪/镜头链/音乐/连贯，人工改策划案 JSON 就是改片。
