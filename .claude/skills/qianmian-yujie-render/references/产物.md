# 产物 · 生成的图放在哪

> **原则：产物是用户的作品，放用户工作区；技能包本身只装「配方」，不装「产物」。**
> 脚本 `scripts/generate.py` 按技能位置自动推导工作区，分享给谁、装进谁的 `.claude/skills/`，产物就自动落到对方工作区，**无需改任何代码**。

## 产物根目录

```
<工作区>/qianmian-yujie-render/
```

- `<工作区>` = 技能所在 `<工作区>/.claude/skills/qianmian-yujie-render/` 的上三层（即 `.claude/` 所在层）。
- **不在 `assets/` 下**——技能产物独立成根目录，不与该工作区其他资产混放。
- 想改位置：在 `scripts/.env` 设 `QYJ_OUTPUT_DIR` 指向任意目录即可。

## 子目录规划（按「产物类型 → 形象」语义桶，对齐 assets 设计思路）

| 目录 | 放什么 | 何时产生 |
|------|--------|---------|
| `候选/<tag>-<时间戳>/` | 选型候选图（`candidate-01.png`…）+ `manifest.json` | `generate.py candidates` |
| `定妆照/<形象>/<形象>.png` | **已确认基准图**——该形象「这张脸」从此锁定 | `generate.py pick` |
| `三视图/<形象>/` | 三视图衍生（正面/侧面/背面/脸特写） | `generate.py derive --kind 三视图` |
| `栏目图/<tag>/` | 栏目/换装/换风格衍生图，`<tag>-01.png`… + `manifest.json` | `generate.py derive`（默认） |
| `视频/<tag>-<时间戳>/` | 视频素材：`<tag>-montage.mp4`（合成）或 `<tag>-01.mp4` + `firstframe` + `check-*.png` + `manifest.json`（图生视频） | `generate.py montage` / `generate.py video` |
| `视频/<title>-<时间戳>/` | **成片**：`<title>.mp4` + `subtitle.srt` + `clips/`（每镜中间片/字卡/旁白/调色版 `*-graded.mp4`）+ `manifest.json`（含 grade/continue_from） | `generate.py compose` |
| `音乐库/` | BGM 曲库（`QYJ_BGM_DIR` 默认指这里）；`compose` 按 `audio.bgm` 文件名命中 | `generate.py`（只读） |
| `音频素材/` | 人工准备的 BGM / 音效（`QYJ_BGM_DIR` 曲库可指这里）；脚本不写，只读 | 人工 |
| `作品集/` | 成品精选（对外展示用，脚本不写，人工整理） | 人工 |
| `拒图/<形象>/<tag>/` 或 `拒图/视频/<tag>-<时间戳>/` | 未过人不变校验的拒图/拒视频（串味 / 无脸），人工复核后再定去留 | `generate.py derive` / `generate.py video` / `generate.py compose` |

## 命名规范

- **候选**：`candidate-01.png`（按 seed 依次编号）。
- **基准图**：`定妆照/<形象码>-<形象名>/<形象码>-<形象名>.png`，例如 `定妆照/A-黛眉/A-黛眉.png`。pick 时用 `--name A-黛眉` 指定；不指定则取候选文件主干名。
- **衍生图**：`<tag>-01.png`，tag 描述这组图是什么，例如 `三视图`、`女仆装`、`霓虹夜风`、`深夜爵士-封面`。同一个 tag 多张会各自独立生成（不同 seed）。
- **视频素材**：`视频/<tag>-<时间戳>/` 内
  - 合成（montage）：`<tag>-montage.mp4` + `manifest.json`
  - 图生视频（video）：`<tag>-01.mp4` + `firstframe.png/jpg`（9:16 首帧）+ `check-50.png`/`check-90.png`（抽帧校验图）+ `manifest.json`
- **成片**：`视频/<title>-<时间戳>/` 内
  - `<title>.mp4`（成片，含音轨）
  - `subtitle.srt`（字幕时间轴）
  - `clips/`（每镜中间片 `<id>.mp4` / 调色版 `<id>-graded.mp4` / 字卡 `<id>-card.png` / 旁白 `voice-<id>.mp3` / 校验图 / 接龙首帧 `<id>-firstframe.jpg`）
  - `manifest.json`（scenes / timing / audio / subtitle / frame_checks / grade / continue_from）
- 每组图 / 视频旁的 `manifest.json` 记录：prompt / model / size / seeds / 校验结果 —— 可复现，审图有据可查。

## 创作中间产物（策划案 / 分镜表）

六段式的中间产物**不属于用户作品图**，但建议保存迭代：

| 产物 | 是什么 | 放哪 |
|------|--------|------|
| **策划案** | 创意产物（① 策划：概念/角色穿搭/文案原子/镜头原子/音乐/连贯；② 脚本与③ 分镜的**设计**都在里面），AI 编辑生成 + 手工精修，**可反复评审改** | 可复制进工作区 `策划案/` 目录留存；示例见技能包 `scripts/examples/策划案-*.demo.json` |
| **分镜表** | 策划案 `produce --emit` 展开的③ 分镜执行计划（含 grade/continue_from） | `produce --emit` 时指定路径；属临时文件，可删（成片产物里已含 manifest） |

> 策划案是「① 策划的活」，分镜表是「③ 分镜的执行计划」——成片不满意，改的是**策划案**，不是分镜表（改完重 emit 重跑）。

## 分享 / 安装指引

1. 复制整个 `qianmian-yujie-render/` 技能包到对方工作区：`<对方工作区>/.claude/skills/`。
2. 对方装依赖：`cd <对方工作区>/.claude/skills/qianmian-yujie-render && uv venv && uv pip install -r scripts/requirements.txt`。
3. 对方复制 `scripts/.env.example` 为 `scripts/.env`，填自己的 `ARK_API_KEY`。
4. 人脸校验模型：脚本会**自动探测** `<工作区>/models/buffalo_l/`；没有才触发 insightface 自动下载到 `~/.insightface`（约需联网一次）。也可设 `INSIGHTFACE_ROOT` 指向含 `models/buffalo_l/` 的目录。
5. 产物自动落在 `<对方工作区>/qianmian-yujie-render/`。

> 本技能是**完整闭环**，独立可共享；包内无任何项目依赖，产物也不回写技能包。
