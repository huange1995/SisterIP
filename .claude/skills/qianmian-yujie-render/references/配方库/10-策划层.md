# 策划层 · 企划书 → 创意产物（produce 策划层）

> **好作品不是「临时手拼」出来的，是「先整体策划原子内容」出来的。** 三层骨架把
> 创作拆成 ①**策划**（编辑设计）→ ②**导演**（渲染契约）→ ③**执行**（渲染成片）：
> 策划层先把 **文案 / 姿势 / 镜头 / 连贯 / 音乐** 一次性设计好，落成一份
> **企划书 JSON**（可读、可改、可评审的迭代单元），再由 `produce` 纯本地零 API
> 展开成导演层能执行的渲染契约。
>
> | 层 | 产物 | 命令 | 谁干 |
> |----|------|------|------|
> | ① 策划层（本层） | **企划书** = 创意产物（概念/文案原子/镜头原子/音乐/连贯） | `produce` | AI 编辑生成 + 手工精修 |
> | ② 导演层 | **渲染契约** = 企划书展开（shotlist，含 grade/continue_from） | `produce --emit` | 自动，可改 |
> | ③ 执行层 | **成片** = 逐镜渲染→拼帧→混音→字幕→封装 | `compose` | 自动 |

**关键原则：企划书自包含。** 姿势/场景/质量等原子文本已经由编辑器从配方库
（01–05 形象/服装/姿势/场景/质量）、文案.md、音乐库**挑好填进企划书**，
`produce` 不解析配方库 markdown，只做拼装与校验。

---

### 字段表

| 段 | 字段 | 必填 | 说明 |
|----|------|------|------|
| 顶层 | `title` | ✅ | 企划名（也用作成片名） |
| | `ratio` / `fps` | | 默认 `9:16` / `24` |
| `concept` | `pitch` | ✅ | **一句话立意**（好作品从一句话开始） |
| | `mood` | ✅ | 情绪关键词数组（慵懒/克制/性感…） |
| | `audience` | | 受众，定腔调 |
| | `style_ref` | | 风格基调（暗调爵士酒吧，胶片颗粒…） |
| | `negative` | | 负面词，缺省用通用负面 |
| `cast` | `anchor` | ✅ | 角色名（定妆照目录名） |
| | `anchor_prompt` | ✅ | **形象锚点**（从配方库 01 挑，自包含） |
| | `outfits[]` | ✅ | 本片用到的服装；`name` 供 shot 引用，`dir`=图集目录，`prompt`=服装描述 |
| | `light` | | 光线（暖黄侧光…） |
| `copy[]` | `id` / `text` | ✅ | 文案原子；`mode`=`subtitle`\|`voiceover`，`tone`=冷/媚/飒…，`scene`=绑到某镜 |
| `shots[]` | `id` / `role` | ✅ | `role`=`establish`\|`detail`\|`hook`（定调/细节/收尾钩子） |
| | `src` | ✅ | `images`（图集连帧）/ `image`（单图）/ `seedance`（图生视频） |
| | 各源字段 | ✅ | `images` 要 `outfit`(或 `dir`)；`image`/`seedance` 要 `base`；`seedance` 要 `pose`/`motion` |
| | `pose` / `scene` / `quality` | | 姿势/场景/质量原子（从配方库挑，自包含） |
| | `cam` / `per`(images) / `dur` | | 机位 / 每图秒数 / 镜头时长 |
| | `copy` | | 绑一条 copy 到该镜 |
| | `continue_from` | | **接龙**：该镜首帧接上一镜末帧（跨镜连贯，P2 生效） |
| `music` | `bgm` / `volume` / `mood` | | 曲库文件名 / 音量 / 气质 |
| `coherence` | `face` | | 人不变规则（成片门阈值说明） |
| | `grade` | | 渲染期统一调色（全片所有镜套同一套，消除跨镜色调漂移） |

## 二、produce 命令（策划层入口，纯本地零 API）

```
python scripts/generate.py produce --inventory
python scripts/generate.py produce --brief <企划书.json> --dry-run    # 创意预览（文案/镜头/音乐/连贯）→ 评审
python scripts/generate.py produce --brief <企划书.json> --prompts    # 逐镜完整 prompt（黄金公式）→ 审查提示词
python scripts/generate.py produce --brief <企划书.json> --emit <契约.json>  # 展开成渲染契约 → 交给 compose
```

- `--inventory`：列出形象库可用资产（栏目图/服装集、定妆照/角色、音乐库/曲目），编辑找料用。
- 展开链：**企划书 → `--emit` 渲染契约 → `compose --script 契约` 出片**。
- 契约含 `grade` / `continue_from` / `voiceover`，现有手写 shotlist 仍可直接 compose（向后兼容）。

## 三、编辑 Checklist（AI 编辑出企划书的工作流）

1. **选题**：一句话 `pitch`（好立意胜过一切；从文案.md 挑/改造）。
2. **读形象库**：`produce --inventory` 看可用 服装集/定妆照/曲目。
3. **定 concept**：mood / audience / style_ref（情绪先定，镜头后定）。
4. **写 copy**：把文案原子绑到对应镜（`scene`），subtitle 是「画面里的话」，voiceover 是「画外音」。
5. **排 shots**：按 **establish → detail → hook** 排功能链：
   - `establish` 定调：图集连帧铺氛围（便宜、快），首镜必是它；
   - `detail` 细节：单图特写（回眸/发丝），把脸打实；
   - `hook` 收尾钩子：seedance 真动（眼神上挑），`continue_from` 接上一镜保证动起来脸不崩。
6. **选 music**：从音乐库按 mood 选，音量 0.2–0.4 起（别盖旁白）。
7. **定 coherence**：face 规则 + grade 统一调色（跨镜色调一致靠它）。

## 四、黄金公式（企划书 → 自动拼装）

衍生（成片）路径不用形象锚点（基准图提供人脸），公式：

```
[服装 prompt] + [姿势 pose] + [场景 scene] + [质量 quality] + [风格基调 style_ref] + [光线 light] + 「；9:16 竖版写真；」+ [负面词]
```

- `sh.use_anchor: true` 时才前置形象锚点（首帧要从 0 出脸时）。
- seedance 镜的动作 prompt 独立拼：`Shot 1: {pose}，{motion}`（可手写 `action` 覆盖多镜）。
- 原子文本在企划书里**不重复**（quality 不重复 style_ref 的词，light 不重复 style_ref 的词），避免拼装出赘词。

## 五、金标准（好企划书 = 好作品的骨架）

1. **pitch 一句话讲得清**：说不清「这条片子讲什么」就不要排镜头。
2. **功能链完整**：establish 定调 → detail 打脸 → hook 收尾，三镜起，镜头数量配情绪节奏。
3. **文案原子先于镜头**：copy 写在 shots 之前，镜头只是文案的画面支撑。
4. **连贯三件套**：策划期设计（姿势/场景尽量延续）+ `continue_from` 接龙 + `grade` 统一调色。
5. **可评审**：`--dry-run` 一眼看出 立意/情绪/镜头链/音乐/连贯，人工改企划书 JSON 就是改片。
