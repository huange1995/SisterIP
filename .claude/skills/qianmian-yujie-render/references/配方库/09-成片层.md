# 成片层 · 渲染契约 → 一条短片（compose 导演+执行层）

> **一条渲染契约 = 一条成片。** `08-视频层.md` 出**单镜头素材**；本层把它们编排成
> **一条带时间轴的短片**：多镜头（两种路线）+ 音频（BGM 混音 + 火山 TTS 旁白）+
> 字幕（字卡烧录 + SRT 导出）+ 成片门（seedance 镜抽帧人不变）+ 统一调色（grade）。
>
> **渲染契约 = 企划书展开产物**（`10-策划层.md`）：策划层 `produce --emit` 把企划书的
> 文案/镜头/音乐/连贯展开成下面的 shotlist JSON；也可直接手写本层契约（向后兼容）。

| 维度 | 本层能力 | 成本 |
|------|---------|------|
| 多镜头·路线 C | `images` / `image` 源本地 montage 连帧（每镜时长/硬切·溶解/机位/烧字卡） | ¥0 |
| 多镜头·路线 A | `seedance` 源图生视频，prompt 写 `Shot N:` 一次出 2–3 镜 | 按秒计费（约 ¥1/秒 720p） |
| 连贯·接龙 | `continue_from`：seedance 镜抽上一镜末帧作首帧参考（跨镜脸/姿态延续） | ¥0 |
| 连贯·调色 | `grade`：全镜拼帧前套同一套 eq+colorbalance，消除跨镜色调漂移 | ¥0 |
| 音频 | BGM（本地曲库）+ 火山 TTS 旁白（按镜对齐）→ ffmpeg 混音 | TTS 免费 1000 次/3 月，后付约 ¥5/万字符 |
| 字幕 | 程序化烧字卡（PIL + 微软雅黑）+ 同步导出 SRT | ¥0 |

## 一、镜头脚本（shotlist JSON）—— 导演怎么说戏

```json
{
  "title": "深夜爵士",
  "ratio": "9:16",
  "fps": 24,
  "scenes": [
    {"id": "s1", "src": "images", "dir": "栏目图/换装秀", "per": 2.5,
     "cuts": "dissolve", "cam": "alternate", "text": "夜晚归她管"},
    {"id": "s2", "src": "image", "base": "定妆照/A-黛眉/A-黛眉.png",
     "dur": 5, "cam": "zoom-in", "text": "酒杯映着灯"},
    {"id": "s3", "src": "seedance", "base": "定妆照/A-黛眉/A-黛眉.png",
     "prompt": "Shot 1: 侧身回眸 发丝微扬 / Shot 2: 指尖划过杯沿 眼神上挑",
     "dur": -1, "firstframe": "derive", "ff_prompt": "9:16 竖版写真，御姐气质，暗调爵士酒吧",
     "continue_from": "s2", "text": "三点后的爵士"}
  ],
  "audio": {
    "bgm": "深夜爵士.mp3",
    "bgm_volume": 0.4,
    "voiceover": [{"scene": "s3", "text": "夜晚归她管，酒杯映着眼里的灯。"}]
  },
  "grade": {"brightness": 0, "contrast": 1.05, "saturation": 0.9, "warmth": 1.0}
}
```

**三种镜头源：**

| src | 产出 | 必填 | 可选 | 成本 |
|-----|------|------|------|------|
| `images` | 图集连帧（每镜 = per × 张数） | `dir`（相对 output_root） | `per` / `cuts`(dissolve·hard) / `cam` / `text` | ¥0 |
| `image` | 单图单镜 Ken Burns | `base` | `dur` / `cam` / `text` | ¥0 |
| `seedance` | Seedance 图生视频 | `base` / `prompt` | `dur`（`-1` = auto 多镜）/ `firstframe`(derive·crop) / `ff_prompt` / `continue_from`（末帧接龙） / `text` | 付费 |

**顶层 `grade`（统一调色）**：`{"brightness": 0, "contrast": 1.05, "saturation": 0.9, "warmth": 1.0}`——
每镜 clip 拼帧前套同一套（ffmpeg `eq` + `colorbalance`），消除跨镜色调漂移。
`warmth` 1.0=不变，>1 偏暖、<1 偏冷；全默认时零成本跳过。来自企划书 `coherence.grade`。

**时间轴是确定的**：同脚本 + 同图集 = 同一 start/dur（SRT 与旁白对齐都靠它）。
`dur: -1`（auto 多镜）时时间轴按 `ARK_VIDEO_DURATION` 估算，实片可能略长。

## 二、跑起来

```
python scripts/generate.py compose --script scripts/深夜爵士.json --dry-run   # 零 API：看镜头/成本/音频/字幕
python scripts/generate.py compose --script scripts/深夜爵士.json             # 真合成
python scripts/generate.py compose --script scripts/深夜爵士.json --no-validate  # 跳过 seedance 镜人不变
```

流程：解析契约 → 逐镜产 clip（本地 montage / Seedance；`continue_from` 镜抽上一镜末帧作首帧）
→ **成片门**（seedance 镜抽帧人不变）→ **统一调色**（顶层 `grade` 套每镜）→ ffmpeg 拼帧
→ 混音（BGM + 旁白）→ 封装 → 导出 SRT → 归档。

**产物**（`视频/<title>-<时间戳>/`）：

```
{title}.mp4           # 成片（含音轨）
subtitle.srt          # 字幕时间轴（供剪映花字精修）
clips/                # 每镜中间片 + 字卡 + 旁白 mp3
manifest.json         # scenes / timing / audio / subtitle / frame_checks
```

## 三、音频三轨怎么配

| 轨 | 配置 | 说明 |
|----|------|------|
| BGM | `audio.bgm` 文件名/路径；或 `QYJ_BGM_DIR` 曲库自动取 | 默认音量 0.5（`bgm_volume` 覆盖），淡入淡出 `QYJ_BGM_FADE` |
| 旁白 | `audio.voiceover[].text`，`scene` 指向镜头 | 火山 TTS，delay = 该镜起始秒；每镜一段 mp3 |
| 无音轨 | 不配 `audio` 段即可 | 保持纯视频现状 |

**火山 TTS 开通**（旁白可选；不配则旁白自动跳过并警告）：
1. [火山引擎控制台](https://console.volcengine.com/) → 语音技术 → 开通「语音合成」。
2. 创建应用拿 **AppID + Access Token**（不是 ARK 密钥）。
3. 填 `scripts/.env`：`ARK_TTS_APPID` / `ARK_TTS_TOKEN`；音色 `ARK_TTS_VOICE`
   （个人实名可开普通音色，默认 `BV700_streaming` 通用女声）。
4. 成本：免费 **1000 次/3 月**，用完后约 **¥5/万字符**。

## 四、多镜头两条路怎么选

- **路线 C（本地连帧）**：素材已经齐全（图集/单图），要的是节奏和机位 → 快、免费。
- **路线 A（Seedance 原生）**：要真动（眼神/发丝/回眸）+ 单次出 2–3 镜 → 需开通视频模型。
- 一条成片里可以**混用**：s1 用图集做节奏铺垫，s3 用 seedance 做「活起来」的高潮镜。
- Seedance 2.0 多镜语法：`Shot 1: … / Shot 2: …`（或【时间轴】`0-3s: …`）。
  默认禁字幕/logo/水印，字幕由本层烧。

## 五、成片门（人不变在成片层的守门）

- `images` / `image` 源：图本身已过 `derive` 门的「人不变」→ 不再重复校验。
- `seedance` 源：出片后自动抽 **50% / 90%** 帧 vs 基准图（insightface，同图片阈值
  ≥0.45 / 0.35）。**任一镜不过 → 整批成片移入 `拒图/视频/`**，人工复核或回改重跑。
- 多镜头提示词原则：**动小不动大**——大幅度动作 = 崩脸 = 整条成片废。

## 六、红线（成片版）

1. **无基准图不能 compose**（seedance 源必须有基准图当首帧/脸参考）。
2. **首帧不能换脸**；旁白/字卡文案先过「媚而不俗」底线。
3. **动小不动大**；字幕不出现低俗 / 引导词 / 违禁词。
4. **成片门是硬门**：seedance 镜人不变不过 = 不能交付。
5. **连贯三件套**：策划期设计（姿势/场景延续）+ `continue_from` 末帧接龙 + `grade` 统一调色——缺一个连贯就打折。
