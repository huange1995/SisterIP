# 视频层 · 单镜头视频配方（可选加工，图是主产品）

> **图是主产品，视频是可选的「加工」**。六个栏目本质上都以图集交付；视频只是
> 让图集「动起来」的两种可选下游，不是必经之路。想要「多条镜头 + 音频 + 字幕 +
> 一条成片」，用**成片层 `compose`**（见 `09-成片层.md`），本层只管单镜头素材。
>
> | 路 | 命令 | 成本 | 效果 | 用在哪 |
> |----|------|------|------|--------|
> | **图集 → 合成** | `montage` | ¥0（纯本地） | 缓慢推近/拉远 / 硬切·溶解 + 可选烧字卡 | 换装秀 / 衣装手记 / 想看哪一面 / 腿部特辑 |
> | **首帧 → 真动** | `video`（Seedance 图生视频） | 按秒计费（约 ¥1/秒 720p 估算） | 真动：眼神 / 发丝 / 回眸 | 深夜爵士等「活起来」的氛围栏目 |

- 任何栏目停在图集（只 `derive`）都是完整交付，不强迫走视频。
- 两条路都基于**已锁基准图**，无基准图先走选型定基准（同衍生门硬约束）。
- 音频 / 字幕 / 多镜头编排统一交给 `09-成片层.md` 的 `compose`；本层命令只出单镜头素材。

---

## 一、montage：图集 → 动态视频（零成本）

```
python scripts/generate.py derive --base <基准图> --prompt "<换装提示词>" --n N --tag <栏目>   # 先出图集
python scripts/generate.py montage --dir <图集目录> [--tag <栏目>] [--per 2.5] \
                                   [--cuts hard|dissolve] [--cam pan|zoom-in|...] \
                                   [--text "开场|高潮"] [--dry-run]
```

- 每张图 Ken Burns 缓慢推近/拉远（相邻图交替方向）+ 淡入淡出（默认 `dissolve`），24fps 输出 9:16 MP4。
- 多镜头（路线 C）升级参数：`--cuts hard` 硬切（快节奏栏目）、`--cam pan` 横移、
  `--text "镜1文案|镜2文案"` 烧字卡（多图逐张）。
- 多镜台词 / 配乐 / 旁白 → 用 `09-成片层.md` 的 `compose` 一键成片（本命令只管单镜头素材）。
- 产物：`视频/<tag>-<时间戳>/<tag>-montage.mp4`。

## 二、video：首帧 → Seedance 图生视频（可选增强，需开通）

```
python scripts/generate.py video \
  --base <基准图.png> --prompt "<动作描述>" \
  [--tag 深夜爵士] [--duration 5|0] [--ratio 9:16] [--resolution 720p] \
  [--firstframe crop|derive] [--ff-prompt "<竖版写真提示词>"] [--dry-run]
```

- **未开通 Seedance 也能 `--dry-run`** 验证全部前置（首帧准备 + 参数组装），开通后直接跑。
- 开通：火山方舟控制台 → 开通管理 → 视频生成模型 `doubao-seedance-2-0-260128`
  （未开通 2.0 可回退 `doubao-seedance-1-0-lite-i2v-250428`）。
- **多镜头（路线 A）**：提示词里写 `Shot 1: … / Shot 2: …` 一次出 2–3 镜；
  `--duration 0` = auto（Seedance 2.0 按内容自定时长）。

### 首帧两种方式（9:16 竖版）

| 方式 | 做法 | 成本 | 何时用 |
|------|------|------|--------|
| `crop`（默认） | 中心裁剪基准图到 9:16 | ¥0 | 快速出，构图以裁切为准 |
| `derive` | Seedream 图生图出竖版写真（以基准图为脸参考） | ¥0.25/次 | 要完整构图 + 脸一致，需 `--ff-prompt` |

## 三、视频提示词语法（和图片是两套）

图片是五层配方；视频提示词 = **画面内容（基准图已定）+ 动作层 + 镜头 + 参数**。

```
[动作层：轻微动，一次只写 1–2 个动作] [镜头：缓慢推近 / 固定机位]
--duration 5 --ratio 9:16 --resolution 720p --watermark false
```

### 动作配方（动小不动大 —— 幅度克制是第一位）

| 部位 | 可用动作（轻） | 禁用（会崩脸/崩形） |
|------|--------------|--------------------|
| 眼神 | 轻抬眼帘 / 缓缓上挑 / 看向镜头 | 快速转动眼球 |
| 手 | 指尖沿杯沿划过 / 指尖拂发 / 轻托腮 | 大幅度挥手 |
| 发 | 发丝微扬 / 发梢轻扫肩 | 甩头 |
| 头/身 | 侧身回眸 / 轻侧身 | 转身 / 走动 / 快跑 |
| 裙/道具 | 裙摆一角微扬 / 轻晃酒杯 / 高跟轻点地面 | 剧烈摆动 |

### 镜头

- **固定机位（`--camerafixed true`）**最稳——人物一致性最好，先出这个档。
- 缓慢推近（subtle zoom-in）次之；避免横移/环绕（容易脸崩）。

### 负面词（文本内嵌）

```
幅度克制、不要转身、不要快动作、不要肢体扭曲、面部不形变、不要第二个人
```

## 四、栏目示例（一键套用）

- **深夜爵士**：`慵懒靠着吧台，指尖沿杯沿划过，眼神缓缓上挑，发丝微扬，固定机位 --duration 5 --ratio 9:16 --resolution 720p --watermark false`
- **换装秀**：`侧身回眸，裙摆被风吹起一角，黑发拂过肩头，镜头缓慢推近 --duration 6 --ratio 9:16 --resolution 720p --watermark false`
- **腿部特辑**：`高跟轻点地面，小腿在镜头前交叉，光线扫过丝袜 --duration 5 --ratio 9:16 --resolution 720p --watermark false`

## 五、人不变怎么守（视频版「衍生门」）

1. **首帧 = 基准图**（或基准图的 9:16 衍生版）→ 起点天然一致。
2. `video` 出片后自动**抽 50% / 90% 处帧** vs 基准图（insightface）：
   - ≥0.45 归档 ✅ ／ 0.35–0.45 存疑 🟡 ／ **<0.35 串味进拒图 ❌**（同图片阈值）。
3. 尾帧脸崩了 → 缩短时长 / 动作改轻 / 加大固定机位再重出。

## 六、红线（视频版）

1. **无基准图不能 video / montage** —— 先选型定基准。
2. **首帧不能换脸** —— derive 首帧也以基准图为脸参考，人不变校验照过。
3. **动小不动大** —— 大幅度动作 = 崩脸崩形 = 废片。
4. **媚而不俗** —— 视频负面词同样硬禁低俗 / 风尘 / 过度暴露。
