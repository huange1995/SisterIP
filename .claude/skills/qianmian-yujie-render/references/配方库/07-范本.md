> 出图：`derive --base <基准图> --kind 三视图 --prompt "<视图提示词>"`，落 `三视图/<形象>/`。
> 背面本就没脸，可用 `--no-validate`；正面 / 侧面仍要过人不变校验。

```
正面：正面站立，双脚自然并拢，双手自然下垂，目视前方，中性站姿，全身照
侧面：侧身站立，头部微侧，目视前方，中性站姿，全身照
背面：背身站立，转头回眸，中性站姿，全身照
脸部特写：正面头部特写，目视镜头，中性表情
```

（每张都接同一套场景 + 主版质量尾缀 + 负面词；可换对应形象场景层 04 的环境）

### 衍生 · 封面（封面 = 阶段二·衍生产物/用途，不是独立出图类型）

> 封面 = 在基准图上按「封面三要素」（红唇 / 丝袜高跟 / 眼神）换装或换场景后，选最能压住画面的一张。
> 提示词只动服装 / 姿势 / 场景 / 质量（不含锚点块）：

```
穿酒红色丝绒旗袍，立领，盘扣，高开衩，肉色丝袜，黑色细高跟8cm，珍珠耳钉，
侧身站立，一脚微前，手扶腰线，指尖轻拂过发尾，回眸看向镜头，眼神微挑，全身照，
夜晚上海街头，霓虹灯，冷蓝与品红霓虹光，湿润路面反射灯光，车流光轨，旗袍开衩在霓虹下拉出腿部光影，
夜景人像摄影，浅景深，背景自然虚化，真实皮肤质感，画面真实自然
```

> **无基准图不能直接衍生**：三视图 / 换装 / 封面没有该形象基准图时不能直接跑（`scripts/generate.py derive` 会校验基准图存在）。
