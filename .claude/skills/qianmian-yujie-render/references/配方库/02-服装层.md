# 配方库·服装层 · 换装库（阶段一候选造型 / 阶段二换装）

> **本层管「衣」，是积木库，不是成品清单。** 服装件 / 丝袜 / 高跟 / 配饰都是**独立原子**，按形象自由组合成造型。
> **换装不改脸**——只动本层，锚点（01 层）不动。这是**阶段二·衍生换装**的硬要求，同样约束阶段一候选变装造型。
> **制服一律走「御姐版」**：成熟、克制、露而不艳；低龄化（水手服等少女感）与低俗/风尘方向不进库。

## 组合公式（搭积木）

```
[连体装 或 (上装 + 下装)]  +  [丝袜 × 高跟]  +  [配饰(可选)]
```

整人 = 形象（01 层，脸锁死）＋ 本层服装组合 ＋ 姿势（03 层）＋ 场景（04 层）＋ 质量（05 层）。

## 搭配规则（红线）

1. **形象风格域**：服装件只能在该形象域内选；跨域（A 配机车、D 配睡裙）= 违和废图。
2. **丝袜 × 高跟自由组合**：24 种 × 28 种任意搭，按气质选；**腿部特写时上身从简不抢戏**（腿线是主角）。
3. **高跟鞋 = 标配**：默认必配细高跟；特例——**泳池下水、浴室赤足** → 赤足不配。
4. **制服走御姐版**：成熟、克制、露而不艳；低龄化 / 低俗 / 风尘方向的搭配一律不进。
5. **换装不改脸**：本层自由组合，锚点（01 层）一个字都不动。
6. **组合后过校验**：组装完的造型按 `../校验.md` 核对（不串味、不违和、腿线+高跟在画面）。
