# 流程 · 业务流程总纲（选型 → 衍生 → 成片 · 三层骨架）

> **本层管「业务顺序」**：所有产出的骨架。核心两步铁律——**先选型定基准，再基于基准衍生；人不变是衍生的硬前提**。
> 成片走**三层骨架**：① 策划（企划书）→ ② 导演（渲染契约）→ ③ 执行（compose），好作品先把原子内容整体策划好再排镜头。
> 对应脚本：`scripts/generate.py` 的 `candidates` / `pick` / `derive` / `produce` / `compose` 等子命令。
> 产物存放见 `产物.md`。

## 一句话

**先出多张候选 → 用户定一张最好的锁为基准 → 之后所有图都以这张为脸参考出衍生（换衣 / 换风格 / 三视图），人不变；要成片则先整体策划企划书，再展开执行。**

## 三层骨架（成片的总纲）

```
① 策划层（编辑）  企划书 JSON = 创意产物：概念 + 文案原子 + 镜头原子 + 音乐 + 连贯   → 可评审可改
② 导演层（执行计划） 渲染契约 = 企划书展开（produce --emit）：含 末帧接龙 continue_from + 统一调色 grade
③ 执行层（渲染）    compose 逐镜渲染 → 拼帧 → 混音 → 字幕 → 成片
```

- 企划书 = **先想清楚再动手**：文案 / 姿势 / 镜头 / 连贯 / 音乐 一次设计好（AI 编辑生成 + 手工精修）。
- 渲染契约 = 导演的「执行计划」，compose 直接吃；也可手写契约（跳过策划层）。
- 配方：策划层 `配方库/10-策划层.md`；导演+执行 `配方库/09-成片层.md`；单镜头素材 `配方库/08-视频层.md`。

## 阶段清单（agent 执行）

**阶段一·选型（无基准图）——六步：**
1. 入口判断：该形象**无**已确认基准图 → 走选型。
2. 读配方：`01-形象层`（锚点块**原样复制**）＋ `02-服装层`（基准款/造型）＋ `03-姿势层`（基准姿势）＋ `04-场景层`（基准场景）＋ `05-质量层`（主版质量尾缀 + 负面词）。
3. 拼提示词（黄金公式，锚点开头，质量尾缀 + 负面词结尾）。
4. `scripts/generate.py candidates --prompt "<完整提示词>" --n 4` 出候选。
5. 用户挑 1 张最好的。
6. `scripts/generate.py pick <候选> --name <形象码>` 锁为基准图 → 过「选型门」（`../校验.md`）。

**阶段二·衍生（有基准图）——五步：**
1. 入口判断：该形象**有**已确认基准图 → 走衍生。
2. 读配方：`02-服装层`（换装）／`03-姿势层`（换姿势）／`04-场景层`＋`05-质量层`（换场景/风格）。**不读 `01-形象层` 锚点**——脸由基准图接管。
3. 拼衍生提示词（**不含锚点块**，只动服装/姿势/场景/质量）。
4. `scripts/generate.py derive --base <基准图> --prompt "<衍生提示词>"` 图生图。
5. 过「衍生门」：人不变校验（≥0.45 归档）+ 媚门；封面再加封面三要素门。配文走 `../文案.md`。

**阶段三·策划成片（要「一条短片」时走）——六步：**
1. **选题**：一句话 `pitch`（好立意胜过一切）。
2. 读形象库（`produce --inventory`）＋ 配方库 01–05 ＋ `文案.md` ＋ 音乐库 → 定 `concept`（情绪/受众/风格）。
3. 写**企划书 JSON**：文案原子（`copy`）先于镜头（`shots`）；镜头按 `establish → detail → hook` 功能链排；seedance 镜用 `continue_from` 接上一镜保证动起来不崩脸。
4. `produce --brief 企划书 --dry-run` 评审 → 手工精修企划书。
5. `produce --brief 企划书 --emit 契约` → `compose --script 契约` 出片（`coherence.grade` 全镜统一调色）。
6. 过「成片门」（seedance 镜抽帧人不变）；看片 → 满意精选进 作品集/，不足回改企划书重跑。

> 三阶段关系：阶段一/二出**图/素材**（人不变的基础），阶段三把素材**编排成片**（人不变守到底）。

## 阶段一 · 选型 / 定基准（必须先做）

| 项 | 内容 |
|----|------|
| 触发 | 用户首次出图 / 换新形象 / 该形象还没有已确认的基准图 |
| 动作 | 拼提示词（五层公式）→ 脚本出 **N 张候选** → 用户挑 1 张最好的 → 锁为基准图 |
| 产出 | 基准图（该形象的「这张脸」从此锁定） |
| 镜头 | 定妆照：全身正面站姿、基准姿态、光均匀、脸清晰 |
| 校验 | 基准图要过「脸合格 + 性感质量门」——它是后面所有衍生的脸参考 |

## 阶段二 · 衍生（必须依赖基准图）

| 项 | 内容 |
|----|------|
| 触发 | 用户要换装 / 换风格 / 三视图 / 封面（该形象已有基准图） |
| 动作 | 拼衍生提示词（只动服装 / 姿势 / 场景 / 质量）→ 脚本**以基准图为参考图**图生图 → 人不变校验 |
| 产出 | 衍生图（换装 / 换风格 / 三视图 / 封面 / 栏目图集） |
| 校验 | 锚点块不重新生成；insightface 人不变校验（≥0.45 归档） |

### 衍生方向（都基于基准图）

- **换装**：改服装件 / 丝袜 / 高跟（服装层 02）
- **换风格**：改后期风格块 / 光位（质量层 05 / 场景层 04）
- **三视图**：正面 / 侧面 / 背面 / 脸部特写 4 张一组，中性姿态
- **封面 / 栏目**：内容图，封面三要素门（红唇 / 丝袜高跟 / 眼神）
- **栏目图集**：同一基准图换装成 N 张（`derive --tag <栏目>`）→ 喂 montage 连帧 / compose 图集镜

## 流程矩阵（什么时候走哪个流程）

| 需求 | 有无基准图 | 走哪个流程 |
|------|-----------|-----------|
| 首次出图 / 换新形象 | 无 | **选型**：出候选 → 确认 → 锁基准 |
| 换装 / 换风格 / 三视图 / 封面 | 有 | **衍生**：基于基准图图生图 |
| 换装但没基准图 | 无 | **先选型定基准，再衍生** |
| 单镜头视频（图集连帧 / 图生视频） | 有 | **素材**：montage / video（08-视频层） |
| 一条短片（多镜头 + 音频 + 字幕） | 有 | **成片**：企划书 → produce → compose（10-策划层 + 09-成片层） |
| 成片但没基准图 | 无 | **先选型定基准，再策划成片** |

## 与脚本的对应

| 本层概念 | scripts/generate.py |
|---------|--------------------|
| 出候选 | `generate.py candidates --prompt "…" --n 4` → `候选/` |
| 确认锁基准 | `generate.py pick <候选目录> <文件> --name <形象码>` → `定妆照/<形象>/` |
| 衍生（换装/风格） | `generate.py derive --base 基准图 --prompt "…"` → `栏目图/<tag>/` |
| 衍生（三视图） | `generate.py derive --base 基准图 --kind 三视图 --prompt "…"` → `三视图/<形象>/` |
| 图集 → 动态视频 | `generate.py montage --dir <图集> --tag <栏目>` → `视频/<tag>-*/`（零成本） |
| 首帧 → 图生视频 | `generate.py video --base 基准图 --prompt "动作"` → `视频/<tag>-*/`（付费，需开通 Seedance） |
| 企划 → 预览/契约 | `generate.py produce --brief 企划书 [--dry-run | --prompts | --emit 契约]`（纯本地零 API） |
| 成片（渲染契约） | `generate.py compose --script <契约或shotlist>` → `视频/<title>-*/` |

> 三视图、换装、封面、成片在**没有该形象基准图时不能直接跑**（脚本 / 校验都会拦）——先选型定基准。
