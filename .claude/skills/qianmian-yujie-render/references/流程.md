# 流程 · 业务流程（选型 → 衍生）

> **本层管「业务顺序」**：先选型定基准，再基于基准衍生。**人不变是衍生的硬前提。**
> 对应脚本：`scripts/generate.py` 的 `candidates` / `pick` / `derive` 子命令。
> 产物存放见 `产物.md`。

## 一句话

**先出多张候选 → 用户定一张最好的锁为基准 → 之后所有图都以这张为脸参考出衍生（换衣 / 换风格 / 三视图），人不变。**

## 阶段清单（agent 执行）

**阶段一·选型（无基准图）——六步：**
1. 入口判断：该形象**无**已确认基准图 → 走选型。
2. 读配方：`01-形象层`（锚点块**原样复制**）＋ `02-服装层`（基准款/造型）＋ `03-姿势层`（基准姿势）＋ `04-场景层`（基准场景）＋ `05-质量层`（主版质量尾缀 + 负面词）。
3. 拼提示词（黄金公式，锚点开头，质量尾缀 + 负面词结尾）。
4. `scripts/generate.py candidates --prompt "<完整提示词>" --n 4` 出候选。
5. 用户挑 1 张最好的。
6. `scripts/generate.py pick <候选> --name <形象码>` 锁为基准图 → 过「选型门」（`../校验.md`）。

**阶段二·衍生（有基准图）——五步：**
1. 入口判断：该形象**有**已确认基准图 → 走衍生。
2. 读配方：`02-服装层`（换装）／`03-姿势层`（换姿势）／`04-场景层`＋`05-质量层`（换场景/风格）。**不读 `01-形象层` 锚点**——脸由基准图接管。
3. 拼衍生提示词（**不含锚点块**，只动服装/姿势/场景/质量）。
4. `scripts/generate.py derive --base <基准图> --prompt "<衍生提示词>"` 图生图。
5. 过「衍生门」：人不变校验（≥0.45 归档）+ 媚门；封面再加封面三要素门。配文走 `../文案.md`。

## 阶段一 · 选型 / 定基准（必须先做）

| 项 | 内容 |
|----|------|
| 触发 | 用户首次出图 / 换新形象 / 该形象还没有已确认的基准图 |
| 动作 | 拼提示词（五层公式）→ 脚本出 **N 张候选** → 用户挑 1 张最好的 → 锁为基准图 |
| 产出 | 基准图（该形象的「这张脸」从此锁定） |
| 镜头 | 定妆照：全身正面站姿、基准姿态、光均匀、脸清晰 |
| 校验 | 基准图要过「脸合格 + 性感质量门」——它是后面所有衍生的脸参考 |

## 阶段二 · 衍生（必须依赖基准图）

| 项 | 内容 |
|----|------|
| 触发 | 用户要换装 / 换风格 / 三视图 / 封面（该形象已有基准图） |
| 动作 | 拼衍生提示词（只动服装 / 姿势 / 场景 / 质量）→ 脚本**以基准图为参考图**图生图 → 人不变校验 |
| 产出 | 衍生图（换装 / 换风格 / 三视图 / 封面） |
| 校验 | 锚点块不重新生成；insightface 人不变校验（≥0.45 归档） |

### 衍生方向（都基于基准图）

- **换装**：改服装件 / 丝袜 / 高跟（服装层 02）
- **换风格**：改后期风格块 / 光位（质量层 05 / 场景层 04）
- **三视图**：正面 / 侧面 / 背面 / 脸部特写 4 张一组，中性姿态
- **封面 / 栏目**：内容图，封面三要素门（红唇 / 丝袜高跟 / 眼神）

## 流程矩阵（什么时候走哪个阶段）

| 需求 | 有无基准图 | 走哪个流程 |
|------|-----------|-----------|
| 首次出图 / 换新形象 | 无 | **选型**：出候选 → 确认 → 锁基准 |
| 换装 / 换风格 / 三视图 / 封面 | 有 | **衍生**：基于基准图图生图 |
| 换装但没基准图 | 无 | **先选型定基准，再衍生** |

## 与脚本的对应

| 本层概念 | scripts/generate.py |
|---------|--------------------|
| 出候选 | `generate.py candidates --prompt "…" --n 4` → `候选/` |
| 确认锁基准 | `generate.py pick <候选目录> <文件> --name <形象码>` → `定妆照/<形象>/` |
| 衍生（换装/风格） | `generate.py derive --base 基准图 --prompt "…"` → `栏目图/<tag>/` |
| 衍生（三视图） | `generate.py derive --base 基准图 --kind 三视图 --prompt "…"` → `三视图/<形象>/` |

> 三视图、换装、封面在没有该形象基准图时**不能直接跑**（脚本 / 校验都会拦）。
