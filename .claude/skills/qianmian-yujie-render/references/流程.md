# 流程 · 六段式业务流程总纲（策划 → 脚本 → 分镜 → 设定 → 素材 → 成片）

> **本层管「业务顺序」**：所有产出的骨架。核心两步铁律——**先选型定基准，再基于基准衍生；人不变是衍生的硬前提**。
> 出高质量短片走**六段式**：① 策划 → ② 脚本 → ③ 分镜 → ④ 设定 → ⑤ 素材 → ⑥ 成片，好作品先把原子内容整体策划好再排镜头。
> 对应脚本：`scripts/generate.py` 的 `candidates` / `pick` / `derive` / `produce` / `compose` 等子命令。
> 产物存放见 `产物.md`。

## 一句话

**先出多张候选 → 用户定一张最好的锁为基准 → 之后所有图都以这张为脸参考出衍生（换衣 / 换风格 / 三视图），人不变；要成片则先整体策划案，再展开分镜表执行。**

## 六段式总纲（出高质量短片的主干线）

```
① 策划  策划案 JSON = 创意产物：概念(concept) + 角色穿搭(cast) + 文案原子(copy) + 镜头原子(shots) + 音乐 + 连贯   → 可评审可改
② 脚本  文案原子 copy[]（字幕/旁白，绑镜）嵌在策划案里                                    → 先文案后镜头
③ 分镜  分镜表 = 策划案展开（produce --emit）：含 末帧接龙 continue_from + 统一调色 grade   → 设计图
④ 设定  角色/穿搭/表演/场景/影像 设定库（只读参考，编辑器挑原子填进策划案）                 → 选料
⑤ 素材  候选 → 锁基准 → 衍生出图（换装/风格/三视图/封面/栏目图集）+ 单镜视频                  → 素材
⑥ 成片  compose 逐镜渲染 → 拼帧 → 调色 → 混音 → 字幕 → 封装                                  → 成片
```

| 段 | 管什么 | 产物 | 命令/入口 | 门禁（`校验.md`） |
|----|--------|------|-----------|-------------------|
| ① 策划 | 策划案 JSON（concept/cast/copy/shots/music/coherence） | 策划案 | `produce --inventory / --dry-run / --prompts` | 策划门：dry-run 评审 |
| ② 脚本 | 文案原子 copy[]（字幕/旁白绑镜） | 片内文案（策划案内嵌） | `produce --dry-run` 预览 | 脚本门：文案合规 |
| ③ 分镜 | 分镜表 shotlist（三源 + continue_from + grade + 时间轴） | 分镜表 JSON | `produce --emit` / 手写 / `compose --dry-run` | 分镜门：镜头功能链 + 连贯设计 |
| ④ 设定 | 角色/穿搭/表演/场景/影像 设定库 + 栏目 + 范本 | 设定库（只读） | Read `设定/*`；`produce --inventory` | 设定门：角色基准 + 设定原子 |
| ⑤ 素材 | 候选 → 锁基准 → 衍生出图；montage/video 单镜视频 | 候选/定妆照/栏目图/三视图/视频素材 | `candidates / pick / derive / montage / video` | 素材门：衍生人不变 + 单镜视频抽帧 |
| ⑥ 成片 | compose 编排成片 + 剪辑 | 成片 `视频/<title>-*/` | `compose [--dry-run \| --no-validate]` | 成片门：seedance 抽帧 + 连贯三件套 |

> 六段关系：① 策划想清楚 → ② 脚本定文案 → ③ 分镜排镜头 → ④ 设定提供原子 → ⑤ 素材把图做出来（人不变的基础）→ ⑥ 成片把素材编排成片（人不变守到底）。
> 只出图不剪片：走到 ⑤ 就是完整交付；要短片才走 ⑥。

## 入口矩阵（什么时候走哪段）

| 需求 | 有无基准图 | 走哪段 |
|------|-----------|--------|
| 首次出图 / 换新形象 | 无 | **⑤ 素材·选型**：出候选 → 确认 → 锁基准（`candidates` + `pick`） |
| 换装 / 换风格 / 三视图 / 封面 | 有 | **⑤ 素材·衍生**：基于基准图图生图（`derive`） |
| 换装但没基准图 | 无 | **先选型定基准，再衍生** |
| 单镜头视频（图集连帧 / 图生视频） | 有 | **⑤ 素材·单镜视频**：montage / video（`素材/02-单镜视频.md`） |
| 一条短片（多镜头 + 音频 + 字幕） | 有 | **① 策划 → ② 脚本 → ③ 分镜 → ⑤ 素材 → ⑥ 成片**：策划案 → produce → compose |
| 成片但没基准图 | 无 | **先选型定基准，再策划成片** |

## 策划案 → 分镜表 → 成片（短片的执行链）

1. **① 策划 + ② 脚本**：写**策划案 JSON**（`策划/01-策划.md`）——文案原子（`copy`，`脚本/01-脚本.md`）先于镜头（`shots`）；镜头按 `establish → detail → hook` 功能链排（`分镜/01-分镜.md`）；seedance 镜用 `continue_from` 接上一镜保证动起来不崩脸。
2. **③ 分镜**：`produce --brief 策划案 --dry-run` 评审 → 手工精修 → `produce --brief 策划案 --emit 分镜表`。
3. **⑤ 素材**：分镜表所需的基准图/图集/单镜视频先用 `candidates/pick/derive/montage/video` 备齐。
4. **⑥ 成片**：`compose --script 分镜表` 出片（`coherence.grade` 全镜统一调色）→ 过「成片门」（seedance 镜抽帧人不变）→ 看片 → 满意精选进 作品集/，不足回改策划案重跑。

> 分镜表是**设计图**，compose 直接吃；也可手写分镜表（跳过策划段，向后兼容）。

## 与脚本的对应

| 六段式概念 | scripts/generate.py |
|-----------|--------------------|
| 策划案 → 预览/分镜表 | `generate.py produce --brief 策划案 [--dry-run \| --prompts \| --emit 分镜表]`（纯本地零 API） |
| 出候选 | `generate.py candidates --prompt "…" --n 4` → `候选/` |
| 确认锁基准 | `generate.py pick <候选目录> <文件> --name <形象码>` → `定妆照/<形象>/` |
| 衍生（换装/风格） | `generate.py derive --base 基准图 --prompt "…"` → `栏目图/<tag>/` |
| 衍生（三视图） | `generate.py derive --base 基准图 --kind 三视图 --prompt "…"` → `三视图/<形象>/` |
| 图集 → 动态视频 | `generate.py montage --dir <图集> --tag <栏目>` → `视频/<tag>-*/`（零成本） |
| 首帧 → 图生视频 | `generate.py video --base 基准图 --prompt "动作"` → `视频/<tag>-*/`（付费，需开通 Seedance） |
| 成片（分镜表） | `generate.py compose --script <分镜表>` → `视频/<title>-*/` |

> 三视图、换装、封面、成片在**没有该形象基准图时不能直接跑**（脚本 / 校验都会拦）——先选型定基准。
